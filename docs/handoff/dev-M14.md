## 7. Deviations so với plan/design

- `IdTokenProvider` cho Google: thêm `iOSServerClientId = webClientId` khi `initialize` (README plugin 8.7.4: cần khi token được xác minh ở server; `aud` của ID token = web client ID — đúng mục "Client IDs" của Supabase web-first). ARCH/TASKS chỉ nêu `webClientId`, `iOSClientId`, `mode`.
- `AuthService.deleteAccount` trả `Result<{ appleRevoked, hadApple, keepData }>` cho UI thay vì `emitOutcome({ kind: 'account-deleted' })` (ARCH §4.7 b.5): D6 nằm trong Settings nên kết quả trả thẳng; `AuthOutcome` (dùng cho `AuthFeedback` toast đăng nhập) không đổi.
- Sync dependency của `AuthService` là thunk `sync: () => AccountDeletionSync | null` (SyncService được tạo sau AuthService trong container); không đổi contract public.
- Route `settings` lazy (ADR-27) để giữ ngân sách 230 kB: chunk `Settings-*.js` ≈ 6,8 kB gzip tách khỏi entry; `createTestRouter(entries, { Settings })` để test cũ mount đồng bộ. Hành vi người dùng không đổi (chunk được SW precache; QC static graph không có chunk này trong closure tĩnh).
- Glyph Apple (OQ-D28): SVG đơn sắc vẽ theo tỉ lệ logo Apple, nhúng inline, `aria-hidden`; **nên thay bằng tệp chính thức từ Apple Design Resources trước khi nộp review** (cùng hộp 17×20, `currentColor`).
- `SignInButtons` nhớ nút vừa bấm ở biến module (không phải state) vì card đổi bố cục `signing-in` làm nhóm nút remount; reset khi hết busy.
- `AccountCard`/`ExportSignInHint`/`SignInButtons` đọc `capabilities` qua `useServices()` (DESIGN: UI chỉ đọc `capabilities`), không thêm prop.
- Mock Supabase: user tạo bởi `id_token` lưu hàng dưới khoá = user id (u1/u2 giữ khoá cũ); `/__test/users` thêm để E2E kiểm "mock không còn u1".
- Test Edge Function lắp chuỗi PEM `BEGIN/END PRIVATE KEY` lúc chạy (không có literal trong nguồn) để không vướng quét bí mật của QC M13 (`tests/qc/m13-r1-static.test.ts`) — DoD 14 chỉ cấm `AgEAMBMGByqGSM49`.

## 8. Known issues và giới hạn

- Google native cần U21 (iOS client ID + URL scheme + Variables) và Supabase Google provider "Client IDs" web + iOS, *Skip nonce check* tắt; nếu NV-14 báo lỗi nonce → bật Skip nonce check (ARCH §10) và ghi lại.
- Sign in with Apple capability phải có trên App ID (developer.apple.com → Identifiers → App ID → Sign in with Apple) — U15/U20; với ký tự động `-allowProvisioningUpdates`, Xcode thường tự thêm capability theo entitlements, nếu lane `testflight` báo "Provisioning profile doesn't support Sign in with Apple" thì bật thủ công trên App ID rồi chạy lại.

- `ios.yml` lane `simulator` build không có `VITE_GOOGLE_*` → Google native ẩn trong bản simulator (đúng thiết kế).
