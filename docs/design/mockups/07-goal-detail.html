Mockup S4 Goal detail, v3.0 (M9). Goal "Đọc sách": daily target 30 min, 2026-10-10 to 2026-12-31 (83 days) with the user's real entries 5, 10, 14, 27 min. The "You" line is the minutes of the latest logged day divided by the minutes of the first logged day (each logged day compared with the previous logged day, multiplied together); days with no time stay flat; it can go below the 0% line. The Ideal line is still +1% a day from the start date. The Y axis is linear and fits both lines (it grows to include negatives), with a solid 0% reference line; labels at 10,000% and above are compact. Use the Scenario select to see the states and the Language switch to check Vietnamese copy at 360 px. Both controls are mockup-only. Hover the chart or focus it and use the arrow keys to read a day. The real chart is a Recharts line chart with the same look. Spec: DESIGN.md S4, 7.1 and 7.6.4.
