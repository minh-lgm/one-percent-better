Account and sync — reference sheet

Phase 2 (DESIGN v2.0, milestones M6–M8). Everything below is a static picture of a state; the real app shows exactly one Account card, one SyncIndicator, one dialog at a time. Strings come from DESIGN.md section 7 (keys in the code snippets of the spec); switch to Tiếng Việt to check string length at 360 px.

1. Account card in Settings (S7) — states A1 … A10

Card is hidden entirely when the build has no cloud configuration. It sits second in Settings: Language, Account, Reminders, Backup, Storage, About.

2. "Sign in with Google" button states (GoogleSignInButton)

Google brand guideline: white fill and gray stroke in the light theme, #131314 fill and #8E918F stroke in the dark theme, the four-color G never recolored, label exactly "Sign in with Google" / "Đăng nhập bằng Google". Height is 44 px (not 40) for the touch target; the font is the system font, not Roboto.

3. SyncIndicator — shown at the top of every main screen once signed in (M7)

Right-aligned in the StatusRow above the page title; hidden when signed out. Changes are announced through a separate visually hidden live region (only for error, offline, expired, and the return to synced), never from the chip itself.

5. Dialogs — real app: modal <dialog> with focus trap (static previews)

D4 starts with Keep selected and focused. Choose "Remove data" in the first preview to see the button turn red. D5 and D3 start with focus on Cancel. On mobile the dialog is a bottom sheet whose body scrolls while the button row stays at the bottom.
