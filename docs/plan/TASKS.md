## 0. Quy ước chung cho mọi milestone

**Trạng thái task.** Cột `Trạng thái` trong file này là trạng thái kế hoạch (khởi tạo `TODO`). Developer báo trạng thái thực tế của từng task trong `docs/handoff/dev-M<n>.md`; orchestrator cập nhật `docs/STATUS.md`.

**Thời gian cố định khi test.** Trừ khi AC ghi khác: "hôm nay" = `2026-10-09` (thứ Sáu), giờ `2026-10-09T10:00:00+07:00`, timezone `Asia/Ho_Chi_Minh`, locale `en-US` (Vitest: `vi.setSystemTime`; Playwright: `page.clock`). AC song ngữ ghi rõ khi chạy ở `vi-VN` (Playwright `test.use({ locale: 'vi-VN' })`; component test `renderWithLocale(ui, 'vi')`). Khi AC nói "chuỗi `vi` của key X" nghĩa là giá trị lấy từ `src/i18n/resources/vi.json` (nguyên văn DESIGN.md), test đọc từ resource thay vì chép literal.

**Quét DOM `vi`** (gọi tắt "quét vi" trong AC): helper `src/test/i18n-scan.ts` (component) và `e2e/helpers/i18n-scan.ts` (E2E) theo ARCH §8: 0 text node/thuộc tính a11y/`document.title` khớp toàn bộ một chuỗi `en` khác bản `vi`, và 0 key thô.

**Definition of done áp dụng cho mọi milestone** (mỗi milestone liệt kê lại kèm phần riêng):

1. Từ thư mục gốc, trên máy đã `npm ci`: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` đều exit code 0 (tương đương `npm run check`). Lint với `--max-warnings 0`.
2. `npm run test:e2e` pass toàn bộ spec của milestone này và mọi milestone trước (không regression).
3. Toàn bộ AC của milestone có test tự động tương ứng, trừ AC ghi rõ "kiểm thủ công".
4. Có `docs/handoff/dev-M<n>.md`: task đã làm và trạng thái, lệnh chạy, cách kiểm từng AC (test nào cover AC nào), bước kiểm thủ công, giới hạn đã biết, thay đổi so với plan (nếu có).
5. `README.md` cập nhật phần liên quan; commit local theo Conventional Commits (`feat(M<n>): …`).
6. **Song ngữ:** mọi chuỗi UI mới của milestone có trong cả `en.json` và `vi.json` (nguyên văn DESIGN.md), không có chuỗi viết thẳng trong JSX; lint, parity test và quét vi của các màn hình mới pass; luồng chính của milestone có ít nhất một E2E chạy ở `vi-VN`.

## M1 — Walking skeleton: goals + ghi phút thủ công + IndexedDB + PWA cơ bản + song ngữ

**Mục tiêu:** Bản chạy được tối thiểu xuyên suốt mọi lớp (UI → service → domain → Dexie/IndexedDB → service worker), có sẵn toolchain build/lint/test/e2e. Xử lý sớm rủi ro PWA/offline và tách lớp. Hạ tầng i18n và toàn bộ chuỗi M1 có cả `en` và `vi` ngay từ đầu (không phải dịch lại về sau).
**Demo:** Mở `npm run preview`, tạo goal "Read" 30 phút/ngày "This year", vào Today ghi 20 phút rồi 10 phút, thấy `30/30` và chỉ báo "+1%". Reload, tắt mạng, reload lần nữa: dữ liệu vẫn còn và vẫn ghi entry được. Chrome hiện nút cài app. Vào Settings chọn "Tiếng Việt": mọi màn hình chuyển sang tiếng Việt ngay, ngày hiện kiểu Việt, tên goal "Read" giữ nguyên; reload vẫn là tiếng Việt. Mở bằng trình duyệt đặt ngôn ngữ `vi-VN` với dữ liệu sạch: app tự hiện tiếng Việt.
**Phụ thuộc:** none (UI cần `docs/design/DESIGN.md`, gồm copy `vi`)
**FR:** FR-01 … FR-10, FR-32 … FR-36. **NFR chạm tới:** NFR-01, 02, 05, 06, 08, 09, 10, 11.
**Thứ tự làm gợi ý:** T1 → T2 → T3 → T4 → T8 → T5 → T6 → T7 (T8 trước UI để màn hình dùng `t()` ngay từ đầu). M1 có 8 task (vượt khung 7) vì i18n phải nằm trong skeleton; T8 là một khối hạ tầng tách riêng để dễ review.
